# DSA Pattern Mastery Plan + Original Question Bank

## How to use this plan
- One pattern per day.
- Solve the selected 3–4 questions independently in Java.
- For each question: explain brute force, optimized approach, why the pattern fits, time/space complexity, and edge cases.
- The selected questions are a first-pass pattern mastery set, not a claim that 3–4 questions exhaust every variation.
- If a pattern has fewer than 3 questions listed in the original source, all listed questions are selected.

Java Math & Geometry Cheat Sheet
// GCD - Euclidean Algorithm
static int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

// LCM
static long lcm(long a, long b) {
    return (a / gcd((int) a, (int) b)) * b;
}

// Binary Exponentiation
static long power(long a, long b) {
    long result = 1;

    while (b > 0) {
        if ((b & 1) == 1) {
            result *= a;
        }

        a *= a;
        b >>= 1;
    }

    return result;
}

// Distance between two points
static double distance(
    int x1, int y1, int x2, int y2
) {
    long dx = (long) x2 - x1;
    long dy = (long) y2 - y1;

    return Math.sqrt(dx * dx + dy * dy);
}

// Cross Product
static long crossProduct(
    int x1, int y1,
    int x2, int y2,
    int x3, int y3
) {
    return (long) (x2 - x1) * (y3 - y1)
         - (long) (y2 - y1) * (x3 - x1);
}
Note: Competitive programming mein modular power ke liye multiplication ko mod ke saath karna zaroori hai. Cross product mein bhi large coordinates ke liye overflow carefully handle karna.

// Check whether ith bit is set

Java Backtracking ka basic template
void backtrack(int start, List<Integer> current,
               int[] nums, List<List<Integer>> result) {

    // Save current answer
    result.add(new ArrayList<>(current));

    for (int i = start; i < nums.length; i++) {

        // Choose
        current.add(nums[i]);

        // Explore
        backtrack(i + 1, current, nums, result);

        // Unchoose
        current.remove(current.size() - 1);
    }
}

Java Graph Template
Adjacency List representation:
import java.util.*;

class Graph {
    int V;
    ArrayList<ArrayList<Integer>> adj;

    Graph(int V) {
        this.V = V;
        adj = new ArrayList<>();

        for (int i = 0; i < V; i++) {
            adj.add(new ArrayList<>());
        }
    }

    void addEdge(int u, int v) {
        adj.get(u).add(v);
        adj.get(v).add(u);
    }

    void bfs(int start) {
        boolean[] visited = new boolean[V];
        Queue<Integer> q = new LinkedList<>();

        q.offer(start);
        visited[start] = true;

        while (!q.isEmpty()) {
            int node = q.poll();

            System.out.print(node + " ");

            for (int neighbour : adj.get(node)) {
                if (!visited[neighbour]) {
                    visited[neighbour] = true;
                    q.offer(neighbour);
                }
            }
        }
    }
}

Java basic template – Merge Intervals
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {

        Arrays.sort(intervals,
            (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> result = new ArrayList<>();

        for (int[] interval : intervals) {

            if (result.isEmpty() ||
                result.get(result.size() - 1)[1] < interval[0]) {

                result.add(interval);

            } else {

                result.get(result.size() - 1)[1] =
                    Math.max(
                        result.get(result.size() - 1)[1],
                        interval[1]
                    );
            }
        }

        return result.toArray(new int[result.size()][]);
    }
}
Important: Yahan < ka matlab hai ki [1, 3] aur [3, 5] overlapping maane ja rahe hain. Kuch interval problems mein endpoint touching ko overlap nahi maana jata, isliye question ki exact condition check karna.
